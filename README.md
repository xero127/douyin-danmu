# 抖音直播后台依旧加载弹幕

[![Greasy Fork](https://img.shields.io/badge/Greasy_Fork-安装脚本-red?style=for-the-badge&logo=tampermonkey)](https://greasyfork.org/zh-CN/scripts/535263)

[支持抖音直播画面显示到b站]直播间页面在后台时依旧能加载弹幕、去除挂机时的节能暂停播放

## 安装

本仓库只保留一个安装入口：[douyin-live-2.0.user.js](https://raw.githubusercontent.com/xero127/douyin-danmu/main/douyin-live-2.0.user.js)。版本统一为 **2.0**，旧版本仍可从 Git 历史查看。

已经安装 2.0.2 的用户需要手动确认替换为此文件；较低的版本号不会被油猴当作更高版本自动升级。安装后刷新相关直播间，避免同时启用多份同类脚本。

## 主要功能

- 保留后台播放保护；同步 B 站原生弹幕时钟，切回页面不强制清空滚动弹幕。
- 在 B 站直播间播放抖音 FLV、HLS、LLS，支持上下分屏和独立音量。
- 手动测试 LLS 和参数未知的 HLS/FLV，补充实际测得的参数，失败源标记叉号。
- 在指定 B 站房间显示新到的抖音弹幕和评论；已有有效连接参数时，关闭抖音页后仍可独立收消息。
- 断流自动恢复默认关闭；开启后重试当前线路，不自动切换到下一条源。悬停状态文字可查看本页打开以来的重载、重连记录。

“显示来源”和“显示抖音弹幕”默认关闭；原先保存的用户选择会保留。LLS 与 H.265 的可用性受浏览器、网络和源本身影响，测试通过不代表所有音画问题都已消除。

完整实现、公式、数据流、边界条件及组件必要性见：[脚本逻辑说明](./SCRIPT_LOGIC.md)。
